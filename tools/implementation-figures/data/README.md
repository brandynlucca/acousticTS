# Implementation figure data

This directory contains only compact, committed numeric inputs required by the
public implementation articles or their supported figure builders.

Appropriate contents include:

- small comparison tables read directly by an implementation article;
- compact reference summaries used by a manifest-listed builder; and
- small pure-R validation products regenerated by package-side tooling.

Raw external-solver results, generated meshes, exploratory outputs, large
comparison suites, timing experiments, and machine-specific source paths do
not belong here. Those inputs should remain in their dedicated validation or
analysis environment; only the compact public result needed by this repository
should be committed here.
